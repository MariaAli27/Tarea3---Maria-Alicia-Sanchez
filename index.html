Diseño Web Responsivo

El diseño web responsivo es una técnica que permite que una página web se adapte automáticamente al tamaño de pantalla del dispositivo.

Su importancia está en mejorar la experiencia del usuario, ya que permite navegar cómodamente desde computadoras, tablets o celulares.

Viewport

El viewport es el área visible de una página web en la pantalla del usuario. Se configura con la etiqueta meta viewport. 

<meta name="viewport" content="width=device-width, initial-scale=1">

Media Queries

Las media queries permiten aplicar estilos diferentes según el tamaño de pantalla del dispositivo. 

@media(max-width: 768px){
    body{
        background-color: #f4f4f4;
    }
}
